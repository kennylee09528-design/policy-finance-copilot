# 微信「普惠Bot」配置指南

适用：普惠业务工作台。完成后，每位员工用**自己的微信**扫码，即可在微信里查询额度、预警、简报、研究报告，发起 PPT、收 Word/PPT 文件、把报告发到邮箱——权限与网页端 / 飞书机器人一致。

> **先看分工**
>
> | 谁 | 做什么 |
> |---|---|
> | **工作台系统管理员** | 系统管理 → 微信普惠Bot：勾选启用、保存；可选地为某人「管理员代绑」生成二维码 |
> | **每位用户** | 手机微信开启「微信ClawBot」插件 → 工作台网页点「绑定微信」→ 扫码（若提示配对码则回填数字） |
> | **我（系统）无法代做** | 微信客户端版本 / 插件灰度由腾讯控制；扫码必须由本人微信完成（条款：独立使用自己的微信号） |

官方显示名：**普惠Bot**。

---

## 1. 手机准备（每位用户）

1. 微信版本：iOS ≥ 8.0.70（Android 以实际灰度为准；插件「逐步放量」，不是人人都有入口）。
2. 打开微信 → **我 → 设置 → 插件** → 启用 **「微信ClawBot」**。
3. 若没有该插件入口：说明当前账号尚未被灰度到，需换已开通的微信号，或等待腾讯放量。

## 2. 工作台启用（管理员）

1. 登录工作台 → **系统管理 → 微信普惠Bot**。
2. 显示名称保持「普惠Bot」（可改）；勾选 **启用微信普惠Bot** → 保存。
3. 页面会显示当前轮询路数（每位已绑定用户一路长轮询）。

## 3. 用户绑定（推荐：自助扫码）

1. 用电脑浏览器登录工作台（业务账号）。
2. 右上角点 **绑定微信**。
3. 用手机微信扫描弹出的二维码（约 5 分钟有效；过期会自动刷新最多几次）。
4. 若手机弹出**配对码**（数字）：在网页输入框填入并提交。
5. 提示「绑定成功」后，打开微信，应能与机器人对话。发送：`帮助`。

**管理员代绑**：系统管理 → 微信普惠Bot → 选择业务账号 →「生成二维码」→ 让该员工用自己的微信扫。扫码的微信 = 该账号的通道。

**解绑**：用户在「绑定微信」弹窗点解除；或管理员在绑定列表点「解绑」。解绑后需重新扫码。若状态变为「需重新扫码」（会话 -14 超时），同样重新扫码即可。

## 4. 能做什么（与飞书一致）

| 发送 | 回复 |
|---|---|
| `额度` / `额度 机构名` | 最新 M5 快照额度（机构账号仅本机构） |
| `预警` | 预警列表 |
| `今日简报` | 最新简报精选（来源+分级） |
| `政策 关键词` | M1 检索（内部） |
| `报告` / `报告 #编号` / `报告文件 #编号` | 已定稿报告；Word 以**文件消息**发出 |
| `生成PPT` | 多轮确认后发 .pptx |
| `发邮箱 报告 #n a@公司域名` | 预览后需回复 `确认发送` |
| `继续` | 补发因条数限制未能发出的内容 |
| `解除绑定` | 解绑本微信 |

每条回答带数据来源 / 数据时间 / 查询时间；数字全部来自数据库。

## 5. 已知限制（来自 2026-10-11 真机 spike）

| 限制 | 说明 |
|---|---|
| **每条提问最多回 10 条** | 第 11 条起 API 返回 `ret=-2 prepare failed`；系统会把剩余内容放入待发队列，您发「继续」或任意新消息时补发 |
| **不能主动骚扰** | 无 context_token 时发送失败（`ret=-2`）；必须用户先发消息 |
| **Markdown** | 实测可渲染（加粗/列表/链接）；系统按 Markdown 友好文本发出 |
| **文件** | docx / pptx / 2MB / 10MB 实测成功；默认上限 **15MB**（25MB 未验证，会提示改走网页/邮箱） |
| **-14 会话超时** | bot_token 失效 → 状态「需重新扫码」，重新绑定 |
| **一人一通道** | 他人无法添加您的 ClawBot；不能入群 |
| **合规** | 业务数据经个人微信与腾讯服务器中转；条款保留腾讯限频/拦截权利——适合作为自愿轻量通道，不建议作为唯一通道 |

## 6. 排障

| 现象 | 处理 |
|---|---|
| 没有「微信ClawBot」插件 | 账号未灰度；换号或等待 |
| 扫码后 `binded_elsewhere` | 该微信已绑到其它设备/实例；先在原处断开或换微信号 |
| 机器人不回 | 是否已启用并绑定成功；事件日志是否有记录；是否被限流 |
| 只回了一部分 | 触发 10 条上限 → 发「继续」；或网页下载 / 发邮箱 |
| 状态「需重新扫码」 | 重新点「绑定微信」扫码 |

更细的协议说明见仓库内 `docs/wechat_clawbot_research.md` 与 `spike_wechat/RESULTS.md`。
