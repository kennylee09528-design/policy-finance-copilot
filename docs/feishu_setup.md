# 飞书机器人 + 邮件发送 · 配置指南

适用：普惠业务工作台（`https://your.domain.example`）。完成后，用户可以**不登录网页**，在飞书里私聊机器人查额度、预警、简报、研究报告，发起 PPT 生成、接收 Word/PPT 文件、把报告发到邮箱。

> **先看这张分工表**
>
> | 谁做 | 做什么 |
> |---|---|
> | **您（开发者 / 应用所有者）** | 在飞书开放平台创建应用、取 App ID / App Secret、开通权限、订阅事件、提交发布；在工作台「系统管理 → 飞书机器人」填写并保存 |
> | **贵司飞书管理员**（只有他有权限） | 在**飞书管理后台**审批应用的上架/发布申请（以及权限范围审批）；如应用需要的权限属于“需管理员审批”类，也由他批准 |
> | **工作台系统管理员**（您） | 工作台里启用机器人、（可选）选意图识别模型、配置 SMTP 与允许发送的邮箱域名 |
> | **每位用户** | 在工作台网页点击右上角「绑定飞书」取绑定码，到飞书私聊机器人发送 `绑定 绑定码` |
>
> **我（系统）无法代您操作飞书后台**：创建应用、审批发布这几步必须由您和贵司飞书管理员完成。**需要您提供/填写的值**：App ID、App Secret（必填）；Verification Token、Encrypt Key（仅 HTTP 回调或启用加密时需要，长连接可不填）；SMTP 主机/端口/账号/密码（或授权码）/发件地址、允许收件的邮箱域名（邮件功能）。所有密钥只在工作台页面输入，加密存储，页面不会再显示。

## 一、飞书开放平台：创建并配置应用（您操作）

1. 浏览器打开 <https://open.feishu.cn/app>（用您的飞书账号登录），点击 **创建企业自建应用**。
   - 应用名称：如「普惠业务工作台助手」；描述：如「查询额度/预警/简报/研究报告，生成 PPT」；上传一个图标。
2. 进入应用 →「**凭证与基础信息**」，记下：
   - **App ID**（形如 `cli_a1b2c3d4e5f6g7h8`）
   - **App Secret**（点“显示”后复制；不要发到群里/邮件里）
3. 左侧「**添加应用能力**」→ 选择 **机器人** → 添加。
4. 左侧「**权限管理**」→ 开通下列权限（可在搜索框搜权限名或权限标识）：

   | 权限标识 | 用途 |
   |---|---|
   | `im:message` | 获取与发送单聊、群组消息 |
   | `im:message:send_as_bot` | 以机器人身份发送消息 |
   | `im:message.p2p_msg:readonly` | 读取用户发给机器人的单聊消息 |
   | `im:message.group_at_msg:readonly` | 接收群聊中 @机器人 的消息 |
   | `im:resource` | 上传文件（用于把 Word / PPT 作为文件消息发回） |

   > 不需要读取通讯录、不需要读取群内所有消息；机器人在群里只会收到 @它 的消息。
5. **（重要的顺序）先去工作台保存凭据并启用，再回来订阅事件**——见第二步。飞书保存“长连接”订阅方式时要求应用的长连接客户端已经在线。

## 二、工作台：填写凭据并启用（您操作，系统管理员）

1. 登录工作台 → **系统管理 → 飞书机器人**。
2. 填写 **App ID**、**App Secret**；“事件接收方式”保持 **长连接（推荐）**；勾选 **启用飞书机器人**；点 **保存**。
   - 长连接是工作台服务器**主动**连到飞书（出站 WebSocket，使用官方 `lark-oapi` SDK），**不需要公网回调地址**，也不受网站外层口令（Caddy Basic Auth）和 IP 证书影响。
3. 点 **测试连接**：显示“成功：机器人『…』”表示 App ID/Secret 正确。页面“连接状态”应显示“连接中/运行中”。
   - 失败常见原因：App Secret 复制多了空格/少了字符（保存时会拦截空白与中文字符）；应用还没添加“机器人”能力；服务器无法访问 `open.feishu.cn`。

## 三、飞书开放平台：订阅事件（您操作）

1. 开放平台 → 应用 →「**事件与回调**」→「**事件配置**」。
2. “订阅方式”选择 **使用长连接接收事件** → 保存（此时工作台的长连接应已在线，否则飞书会提示未检测到连接）。
3. 点 **添加事件** → 搜索并添加 **接收消息 `im.message.receive_v1`**（需要上面开通的消息读取权限）。保存。

> 备选：**HTTP 回调**。把订阅方式改为“将事件发送至开发者服务器”，请求地址填 `https://your.domain.example/api/feishu/events`，并把飞书页面里的 Verification Token（及 Encrypt Key，如启用）填到工作台同名字段、接收方式选“HTTP 回调”。**注意**：①飞书服务器无法通过网站外层的 Basic Auth，需按 `deploy/Caddyfile` 里的注释给这一个路径放行（其它路径仍需口令）并 `docker compose restart caddy`；②飞书要求回调地址 HTTPS 证书受信，IP 证书是否被接受未经真实验证。**除非长连接不可用，请使用长连接。**

## 四、飞书开放平台：发布版本 + 管理员审批

1. 应用 →「**版本管理与发布**」→ **创建版本**：填写版本号（如 `1.0.0`）、更新说明；**可用范围**选择能使用机器人的人员/部门（建议先选普惠部相关人员 + 需要使用的合作机构联系人；范围外的人搜不到机器人）。
2. 点 **保存并发布 / 申请发布**。
3. **【只有贵司飞书管理员能做】** 管理员登录 **飞书管理后台**（<https://feishu.cn/admin>）→ **工作台 → 应用管理/应用审核**，找到该应用的发布申请，**审核通过**。企业自建应用在管理员通过前，其他人无法使用；之后**每次新增权限或改可用范围，都需要重新创建版本并再次审批**。
4. 审批通过后，在飞书里搜索机器人名称即可发起单聊。把机器人拉进群时，群里需要 **@机器人** 才会回复。

## 五、用户绑定（每位用户操作）

1. 在电脑浏览器登录工作台 → 右上角点 **绑定飞书** → 得到 8 位**一次性绑定码**（默认 10 分钟有效）。
2. 在飞书**私聊**机器人，发送：`绑定 AB12CD34`。成功后机器人会回复“绑定成功：姓名（身份）”。
3. 管理员也可在 **系统管理 → 飞书机器人 → 已绑定账号** 里按 open_id 手工映射（未绑定用户发消息后，open_id 会出现在“事件日志”里）；也可在此解绑。
4. 权限规则：机器人能展示的内容 = 该账号在网页端能看的内容。
   - **合作机构账号**：只能查本机构的 M5 额度/预警、已发布的 M2 简报；不能使用 M1 政策检索、M3 研究报告、PPT、发邮箱。
   - **普惠部内部账号**：全部功能。
   - 群聊默认**不回答内部数据**（额度、预警、报告、PPT、邮件请私聊；群里只答简报/政策检索），可在管理页开关。
   - 账号被停用 / 需改密时，机器人会拒绝并提示。

## 六、机器人能做什么（用户视角）

私聊发送：`帮助` 查看清单。

| 您发 | 机器人回复 |
|---|---|
| `额度` / `额度 某某机构` | 最新 M5 快照的额度使用情况（内部：全网汇总 + 使用率最高机构；机构账号：本机构），注明快照编号、统计日期、查询时间 |
| `预警` | 预警列表（超额/即将用尽/进度滞后/环比波动） |
| `今日简报` | 最新已发布的 M2 简报精选，含来源与权威分级（A1…） |
| `政策 融资担保 降费` | M1 知识库检索：标题、来源、分级、发布时间、链接（内部账号） |
| `报告` / `报告 关键词` / `报告 #3` | 已定稿研究报告列表 / 摘录（草稿不提供） |
| `报告文件 #3` | 把带水印的 Word 作为**文件消息**发给您（仅已定稿且无标红） |
| `生成PPT` | 多轮：选类型 → 选数据来源 → 确认需求单（可回答澄清问题）→ 确认大纲 → 生成并把 .pptx 作为文件发回；`取消` 随时放弃 |
| `PPT文件 #任务号` | 获取已生成的 PPT |
| `发邮箱 报告 #3 name@公司域名` | 先预览收件人/主题/附件，回复 `确认发送` 才会发；含 M5 敏感数据的报告须回复 `确认涉密发送` |
| 其它自然语言 | 先按关键词规则识别；识别不了时才用大模型**只做意图分类**（只发送您的提问文字，不发送任何业务数据）；没配模型则提示“没太明白” |

所有回复都带“数据来源 / 数据时间 / 查询时间”；数字全部来自数据库。每条消息记入「系统管理 → 飞书机器人 → 事件日志」和「操作留痕」（含绑定账号）；每人每分钟限 15 条（可改）；飞书重试的重复事件按 event_id / message_id 自动去重。

# 邮件发送（SMTP）配置（系统管理员操作）

「系统管理 → **邮件发送**」：

| 项 | 说明（示例） |
|---|---|
| SMTP 服务器 / 端口 / 加密 | 企业微信邮箱 `smtp.exmail.qq.com` 465 SSL；阿里企业邮 `smtp.qiye.aliyun.com` 465 SSL；163 `smtp.163.com` 465 SSL；587 用 STARTTLS |
| 登录账号 / 密码 | 邮箱账号 + **密码或“客户端授权码”**（很多邮箱需先在邮箱设置里开启 SMTP 并生成授权码）；加密存储，不回显 |
| 发件人名称 / 地址 | 发件地址需与登录账号一致或被该邮箱允许 |
| **允许的收件邮箱域名** | **必填**，如 `example.com`；`*.corp.com` 表示含子域。**为空 = 一律禁止发送**（内部资料不得外发） |
| 限额 | 单封收件人上限、每人每小时封数、附件合计上限（MB） |
| 启用 | 勾选后才可发送；先点“发送测试邮件” |

使用：M3 研究报告（**已定稿**）、M2 简报（**已发布**）、PPT 文件旁的 **发送到邮箱** → 填收件人/主题/留言 → **确认收件人弹窗** → 发送。只能发已定稿且无标红的报告；含 M5 敏感数据须勾选确认；邮件正文与附件带「内部资料 注意保密」和发送人信息；记录在「操作留痕 → 邮件发送记录」（可归档/删除，与其他执行记录一致）。

## 七、故障排查

| 现象 | 处理 |
|---|---|
| 工作台“连接状态”一直“连接失败” | 看 `docker compose logs app` 与数据卷里的 `feishu_ws.log`；多为 App Secret 错误、应用未添加机器人、服务器出站被限制 |
| 飞书里机器人不回复 | ① 是否在“事件配置”添加了 `im.message.receive_v1`；② 版本是否已发布并被管理员审批；③ 您是否在可用范围内；④ 群聊是否 @ 了机器人；⑤ 事件日志有没有这条消息 |
| 回复“还没绑定” | 按第五步绑定；绑定码一次性、10 分钟有效 |
| 回复“请私聊” | 群聊默认不回答内部数据，私聊使用 |
| 收到文件失败 | 检查 `im:resource` 权限是否已开通并**重新发布**；文件超过 30MB 飞书不收 |
| 邮件发不出 | 系统管理 → 邮件发送 → 发送测试邮件看具体错误；域名白名单是否包含收件人域名 |

## 八、安全说明

- App Secret / Verification Token / Encrypt Key / SMTP 密码均用服务器密钥 Fernet 加密存储，接口与页面永不返回明文。
- 大模型（若配置“意图识别”）只收到用户提问文字；额度/报告/简报内容不会发给大模型；模型环节为独立槽位 `feishu.router`。
- 绑定码一次性、短时效、哈希存储、防暴力尝试（每人 10 分钟 5 次）。
- HTTP 回调（如启用）校验 Verification Token；配置 Encrypt Key 时校验签名并解密。
