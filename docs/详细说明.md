# 详细说明（部署 · 配置 · 模块）

FastAPI + SQLite + 原生 HTML/CSS/JS 单体应用，ECharts 本地化（`static/vendor/echarts.min.js`，不依赖 CDN）。

| 模块 | 一期状态 |
|---|---|
| M4 机构授信管理 | **可用**：附件2 十张分表导入 → 系数测算（与示例表 W/X 逐行一致）→ 第三次人工调整 / 民投完成率调整（原因必填、留痕）→ 方案版本（草稿/已上会/已批复、对比、回滚）→ 导出测算表 Excel、请示 Word。重算结果含口径版本 / 参数版本 / 数据集 / calc.py 哈希。内部可查阅「口径说明」页（列级白话公式）；口径说明 xlsx 与测算表中的「口径说明」工作表仅系统管理员导出。缺系数仍是告警且不算 U/X |
| M5 机构看板 | **可用**：四端口国担台账上传 → 汇总页/分机构页（同「1.业务额度使用情况」版式）→ 预警、环比说明、图表、快照回溯、导出 Excel；机构用户行级权限 |
| M1 财金协同知识库 | **搜索驱动采集可用**（需配置搜索 Key）：查询模板 × 主题 × 地域 → 联网搜索 → 权威发布方规则过滤分级 → 抓取正文 → AI 要点摘要；定时任务。内部同事可在 M1「补录政策」粘贴单条链接或上传 PDF/Word 自行入库（`provider=manual`，记录上传人；合作机构不可用）。条目有政策效力字段（默认未知），可人工改状态与日期；首页列出 90 天内到期的现行有效文件；问答/检索对非现行有效附「勿作决策依据」（未知则提示效力未核定） |
| M2 今日 Brief | **可用**：取 M1 最近 24h（可配）条目 → 4.2 重要度打分（权重管理员可改）→ ★★★/★★/★ → 4.3 模板五栏 → 关键数字来源校验（原文找不到即拦截，列入「待核实」）→ 编辑（调档/排除/改要点，反哺 M1「人工校正」）→ 发布锁定 → 按日期归档、多版本、补生成历史日期 → 导出 Word / Markdown；每日 07:30（北京时间）自动生成 |
| M3 行业研究院 | **三 Agent 写作可用**（需配置模型）：研究及写作（M1 FTS5 检索 + 联网检索抓原文 + M5 数据库取数占位填数）→ 核对（规则层逐句核出处，标红拦截 +《引用来源登记表》+ 可选模型提示）→ 人工终稿（标红须改正或填理由确认）→ 总结（初稿/终稿 diff → 写作规范库，下次注入）→ 导出 Word（含登记表、修改痕迹）；实时进度（阶段/段落/用时/tokens）；公开资料联网检索与登记仍保留 |
| 单机构自测 | `/selftest`，对机构开放，不显示任何其他机构信息 |
| 系统管理 | 管理员登录 + 大模型供应商/模型配置 |

## 一、本地运行

```bash
cd app
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
# 浏览器打开 http://localhost:8000
```
- 数据目录默认 `app/data/`（环境变量 `PH_DATA_DIR` 可改），SQLite 文件 `workbench.db`。
- 演示数据：M4 页「导入附件2 样例」、M5 页「一键导入样例」，均来自 `samples/` 中的原始 Excel。
- 测试：`.venv/bin/python -m pytest -q tests/`（M4/M5 验收比对 + 管理员/大模型层）。

## 二、管理员账号
- **没有默认密码。** 首次启动随机生成初始密码，写入 `data/admin_initial_password.txt`（权限 600），用户名 `admin`。
- 首次登录强制修改密码（≥10 位，含字母与数字/符号），修改后该文件自动删除。
- 忘记密码 / 重置：`python -m app.cli reset-admin [--username admin] [--password 新密码]`（不带密码则随机生成并写入上述文件；所有会话失效，下次登录须改密）。
- 密码 bcrypt 哈希；会话为服务端存储的随机令牌（HttpOnly、SameSite=Strict、HTTPS 下 Secure），8 小时有效；同一 IP+用户 5 分钟内失败 5 次即锁定。

## 三、大模型配置（系统管理 → 大模型配置）
- 统一 **OpenAI 兼容适配器**（`POST {base_url}/chat/completions`），内置预设：**公司私有模型（自有算力云，API 调用）**、DeepSeek、通义千问/百炼、腾讯混元、智谱 GLM、豆包/火山方舟、Kimi/Moonshot、文心/千帆、MiniMax（国内 api.minimaxi.com / 国际 api.minimax.io；自动剥离 <think> 思考内容、温度夹紧到 0.01~2、思考 token 计入长度故 max_completion_tokens ≥ 2048）、**MiniMax（包月 Token Plan）**（订阅 Key sk-cp-…，默认 Anthropic 兼容 `https://api.minimax.cn/anthropic`；官方定位个人交互式使用、生产建议按量付费，受 5 小时/周额度窗口与限流约束）、通用 Anthropic 兼容（base_url 以 `/anthropic` 结尾即自动走 Messages 协议）、通用 OpenAI 兼容。预设只是默认的 base_url 与示例模型 ID，均可修改（模型型号以厂商控制台为准）。
- 页面可视化：新增/编辑/启停供应商和模型（名称、base_url、API Key、模型 ID、temperature/top_p/max_tokens），「测试连接」按钮。
- API Key 用 Fernet 加密存库（密钥：环境变量 `PH_SECRET_KEY`，或自动生成 `data/secret.key`，权限 600）；页面只显示掩码，接口永不返回明文或密文。**请备份 secret.key，丢失后需重新录入各 Key。**
- `允许处理敏感数据` 开关：M4/M5（机构授信、额度使用数据，需求第 10 章）只能调用开启了该开关的模型，后端强制校验（返回 403）。建议仅对「公司私有模型」开启。
- 使用位置：M2 简报生成、M3 三个 Agent（写作/核对/总结）页面顶部下拉选择模型并可试运行；M5 汇总页「AI 润色环比说明」（仅列出已授权敏感数据的模型）。

## 三之二、联网搜索（系统管理 → 联网搜索）
- 预设：**Tavily**（`POST https://api.tavily.com/search`，Bearer Key）与 **阿里云 IQS 通义晓搜 UnifiedSearch**（`POST https://cloud-iqs.aliyuncs.com/search/unified`，Bearer/X-API-Key；`engineType` 可选 Generic / GenericAdvanced / CNLiteBasic / CNAuto / GlobalAdvanced）。接口地址、参数均可改。
- Key 与大模型 Key 相同方式加密保存、掩码显示、不回传浏览器；「测试」按钮；可启停、设一个为默认（M1、M3 使用启用中的默认供应商）。
- 结果统一为 `{标题, 链接, 发布日期, 摘要, 站点}`。

## 三之三、M1 搜索驱动采集（系统管理 → M1 采集规则与查询模板）
- **不依赖固定网站清单**：按「查询模板（默认 `{region} {topic}`）× 主题词 × 地域」生成检索词。地域分层（需求 3.1.1）：国家、广东本省（默认每轮必扫）、广东 20 个地市、5 个重点特殊财政管理城市（深圳/宁波/青岛/大连/厦门）、其余 30 个省级行政区（轮转）。
- 成本控制：「每轮最多检索次数」（默认 60）；必扫层级优先，其余组合按游标轮转，页面显示多少轮覆盖一遍。要做到 31 省每日全覆盖需提高上限（约 主题数×57 次/天）。
- **权威发布方规则**（可视化编辑，首条命中生效，域名自动含子域）：默认含 中国政府网、财政部、人民银行、金融监管总局、发改委、工信部、科技部、人社部、农业农村部、广东省财政厅、广东省地方金融管理局、广东省政府、通配 `gov.cn`（A1/A2：URL 路径命中正式文件路径正则判 A1，否则 A2）；新华社、人民网、经济日报、金融时报、证券时报、第一财经、21世纪经济报道、央视网（B1）；腾讯新闻（B2）；微信公众号（C1）；其余站点为 C2。默认只保留 A1/A2/B1，可改。
- 保留的结果：URL 归一化去重（去 utm 等参数）+ 同标题归并；抓取正文（httpx + lxml 轻量正文抽取，自动识别 GBK/UTF-8，逐跳校验禁止访问内网地址、3MB/15s 上限；PDF 记链接暂不解析）；如在 M1 页面选择了「要点摘要」模型，每轮对新条目提炼 3–5 条要点（严禁编造，原文未提及写“未提及”）。
- 需要渲染 JS 的站点可将 `app/m1/fetch.py` 的 `fetch()` 替换为 Crawl4AI 实现（接口不变），一期未引入以控制镜像体积。
- 定时：在配置中开启并填写每日时间（如 07:00），应用进程内调度（单进程运行）。也可「立即采集一轮」。
- **政策效力**（人工核定，不自动抽失效日）：`validity_status` 为现行有效 / 已废止 / 已失效 / 未知（默认未知），另有生效日、失效日、废止日、替代文件、文号与备注。M1 首页列出「即将到期（90天内）」：现行有效且失效日期早于今天起 90 天（含已过期未改状态）。语义检索、知识库问答和飞书/微信政策检索对非现行有效附效力提示（未知为「效力未核定」），并写明勿作决策依据。
- **同事补录**（M1 → 补录政策，仅 `admin` / `internal`）：① 粘贴一条 http(s) 链接，复用抓取、清洗、权威域名分级和要点摘要，不跑整轮搜索；② 上传 PDF 或 Word（.docx），抽出正文后用 M1「要点摘要」模型预填标题、发布机构、文号、日期、要点和来源等级，人工可改，改等级则 `level_manual=1`。两条都记 `provider=manual` 和上传人，效力默认未知，`reviewed_at` 为空并出现在待复核。归一化链接已存在，或标题+发布机构+文号三者齐全且全等，直接拒绝并返回已有条目；仅规范化标题相同可拒绝，或勾选后仍入库并写 `duplicate_of`（默认列表不显示）。扫描版 PDF 抽不出文字时返回明确错误。上传文件保存在数据目录 `m1_uploads/`，条目留原文件名与相对路径。

## 三之四、M2 今日行业 Brief（系统管理 → M2 简报规则）
- 打分 = 来源等级分×30% + 政策层级分×25% + 业务相关度×30% + 时效性×15%（权重之和须为 1，可改）。等级分 A1 100 / A2 85 / B1 70 / B2 60 / C1 45 / C2 25；层级分 国家 100 / 广东本省 95 / 其他省级 80 / 重点城市 70 / 地市 55；业务相关度 = 命中关键词权重累加（上限 100，关键词表可编辑）；时效 24h 100 / 3 天 70 / 7 天 40 / 更早 10。≥80 ★★★（今日必读），60–79 ★★（广东及国家 → 值得关注；他省/重点城市 → 同业动态），<60 ★（折叠浏览）。
- 要点来源优先级：M1 已有 AI 要点 → M2 模型提炼（只用原文、温度 0.1）→ 抽取式（原文句子）。**要点与关键数字中的每个数字都必须能在该条原文中找到**，否则条目被拦截，不进正文，只在「五、待核实提示」列出；非 A1 来源的数字单列提醒。
- 「数据速览」直接取 M5 最新快照数据库值（不经大模型）。
- 同一日期可多次生成（v1、v2…）；发布后锁定；发布前若正文中出现被拦截条目则拒绝发布。
- 定时：应用进程内每 30 秒检查一次，到达设定时间（默认 07:30，容器 TZ=Asia/Shanghai）后当日只自动生成一次。

## 三之五、M3 写作 Agent（系统管理 → M3 写作 Agent）
- 每个 Agent（研究及写作 / 核对 / 总结）单独配置：模型、temperature、top_p、超时、启用；提示词模板**版本化**（保存即新版本，可回切任一历史版本；任务记录所用版本号）；研究及写作 Agent 的「知识范围」= 可用来源等级、政策层级、知识库/联网条数。
- 写作：资料编号 S1…Sn（M1 知识库 FTS5 trigram 全文检索，<3 字的词 LIKE 兜底；联网检索结果会抓取原文正文用于核对）；M5 数据以 `{{F1}}` 占位，**写作模型看不到数值**，由系统从数据库填入并标注 `[M5]`。勾选 M5 时所有 Agent 必须使用「允许处理敏感数据」的模型。
- 核对（规则层，确定性）：凡含金额/比例/数量、排名、案例/机构/文件名称的句子——无 `[Sk]` 标注 → 未找到出处；有标注但数字/名称在所引来源原文中找不到 → 存疑；两者均标红并阻止定稿。模型核对只追加提示，不能解除标红。
- 人工修改终稿后自动复核；标红句须改正，或填写理由「人工确认」（留痕）后方可定稿。
- 总结：初稿/终稿逐句 diff → 总结 Agent 提炼「措辞/结构/口径」规范（无模型时规则提炼替换对）→ 写作规范库（可停用/删除/手工新增心得）→ 下次写作注入系统提示词。

## 四、服务器部署（Docker，推荐）
目标：Ubuntu 24.04，已安装 Docker + compose，80/443 空闲，已有 Let's Encrypt IP 证书 `/etc/letsencrypt/live/your.domain.example/{fullchain,privkey}.pem`。

```bash
# 把 app/ 目录上传到服务器，例如 /opt/puhui-workbench
cd /opt/puhui-workbench
docker compose up -d --build
docker compose exec app cat /data/admin_initial_password.txt   # 查看初始管理员密码
# 访问 https://your.domain.example （http 自动 301 跳转 https）
```
- `app` 容器只在内网暴露 8000；`caddy:2-alpine` 监听 80/443，使用只读挂载的 `/etc/letsencrypt` 证书（`deploy/Caddyfile`，`auto_https off` + `default_sni`，不会自行申请证书）。
- 业务数据在命名卷 `ph_data`（容器内 `/data`：数据库、secret.key、导出文件）。备份：`docker run --rm -v puhui-workbench_ph_data:/d -v $PWD:/b alpine tar czf /b/ph_data.tgz -C /d .`（卷名前缀为 compose 项目名）。
- **证书续期**：IP 证书有效期短，certbot 续期后需让 Caddy 重新加载：把 `deploy/certbot-deploy-hook.sh` 复制到 `/etc/letsencrypt/renewal-hooks/deploy/` 并改好目录，或手动 `docker compose exec caddy caddy reload --config /etc/caddy/Caddyfile --force`。
- 国内拉取镜像慢时，给 Docker 配置镜像加速；pip 默认用腾讯云镜像（`docker compose build --build-arg PIP_INDEX_URL=...` 可改）。
- 重置管理员密码：`docker compose exec app python -m app.cli reset-admin`。

## 五、非 Docker 部署（systemd + 可选 nginx）
```bash
sudo useradd -r -m puhui && sudo cp -r app /opt/puhui-workbench && cd /opt/puhui-workbench

```

## 七、权限说明（一期）
- 管理员登录保护「系统管理」。业务页面的角色（普惠部内部 / 合作机构用户）一期以页面右上角「演示身份」切换（请求头 X-Role / X-Org），用于演示 M4 仅内部可见、M5 机构只看本机构行；二期接入正式统一登录时替换 `app/auth.py` 的 `current_user` 即可。
- **公网部署前请注意**：当前业务页面未强制登录，任何能访问网址的人都可以切换身份查看 M4/M5 数据。上线真实数据前应启用统一登录，或在 Caddy 增加 IP 白名单/基础认证。

## PPT 生成 Agent（导航「PPT 生成」）
四类演示稿：① 额度使用情况汇报（M5 快照）② 授信方案上会材料（M4 方案版本）③ 政策简报/月度汇编（M2 简报日期范围）④ 研究报告配套演示稿（M3 已定稿任务）。

流程（向导 + 对话）：选择类型与数据 → Agent 提出澄清问题并给出需求单（人工修改确认）→ Agent 生成大纲（逐页可改类型/标题/要点/数据、排序、增删；可按意见重做）→ 确认后生成 .pptx（每次生成一个版本，历史可下载）。

数字铁律：大模型只看到「数据目录」（编号+名称，无数值），只写结构/标题/要点；要点中的数字只能写 `{{F1}}` 占位符，由代码替换为数据库值；图表/表格/文字块由 data 编号引用，内容由代码插入。含字面数字的标题/要点（无论来自模型还是人工编辑）一律丢弃并提示。生成后逐页做数字溯源检查（文本/表格中每个数字须出现在数据包中、图表序列须与数据包一致），结果随版本保存。

- 渲染：python-pptx，16:9 工作台深红主题；原生可编辑图表（柱/条/堆积/折线）与表格；长表/多类别图表/长文字块自动分页；页脚「内部资料 注意保密」与页码
- 模板：系统管理 · PPT Agent 可上传公司 .pptx 模板（按版式名称匹配封面/节标题/仅标题），设为默认或在新建时选择
- 敏感数据：额度汇报、授信上会材料，以及使用了 M5 数据的研究报告配套稿，只能使用「允许处理敏感数据」的模型；未配置模型时按规则生成需求单与大纲（仍需两次人工确认）
- 管理员：默认模型/temperature/top_p/超时/最大页数；四类提示词模板版本化（新建即启用、可回切），任务记录所用版本
- 缩略图：服务器装有 LibreOffice 时自动生成 PNG 缩略图；容器镜像默认不装（约 +500MB），页面以大纲预览代替
- 样例：`.venv/bin/python scripts/ppt_samples.py <输出目录>`（临时数据目录、本地桩模型，生成四类样例与 PNG 预览）
